## 2. 원칙

1. 화면마다 초점 하나, 주 행동 하나. 주 행동은 오른쪽 아래 노란 알약 버튼(높이 120) 하나이고 뒤로는 왼쪽 아래 글자 버튼이다. 하단 바는 없다.
2. 굵기 위계: 제목 700, 소제목 600, 본문 450에서 500, 라벨 600, 캡션 500. 800 이상은 쓰지 않는다. 최소 400.
3. 크기: 제목 88, 소제목 48, 리드 40, 본문 36, 라벨과 캡션 28. 28 미만 글자는 없다.
4. 바탕은 평평한 `bg-base`. 격자, 점자 블록, 흐르는 띠를 걷어 낸다. 면 구분은 `bg-panel`, `bg-raised` 단계로만 한다.
5. 지하철 길찾기 어휘는 구조로만 쓴다. 상단 왼쪽 역명판(승강장 번호 원형 배지 + 현재 정거장), 상단 오른쪽 "Next stop", 상단 아래 한 줄 노선(정거장 점과 진행), 완료 화면의 출구 표지. 장식용 반복은 없다.
6. 한영 전환은 상단 오른쪽 언어 버튼으로 어느 단계에서나 가능하다. 모든 문구는 `<T>`(같은 칸 겹침)라 레이아웃이 움직이지 않는다.

## 3. 온보딩: 세 번만

| 순간 | 형태 | 내용 |
| --- | --- | --- |
| 탑승 안내(intro) | 단계 자체 | 네 정거장 노선(Choose, Pay, Pose, Print) 한 장 |
| 결제(카드, 삼성페이 선택 직후) | 화면 오른쪽 칸의 팁 카드 | 기기 그림에서 단말기 위치를 표시하고 "Got it"으로 닫는다 |
| 첫 촬영 전(ready) | 미리보기 옆 칸의 팁 카드 | 기기 그림에서 렌즈 위치를 표시하고 "Got it"으로 닫는다 |

팁은 화면을 덮지 않는다. 자기 칸 안에서 열리고, 닫으면 같은 칸에 짧은 안내가 남는다. 닫은 기록은 컨트롤러의 React 상태(`coach.seen`)에만 있고 세션이 끝나면(처음으로) 지워진다. 저장소는 쓰지 않는다. 시뮬레이터의 기기 투어(`?tour=`)는 버튼으로만 열린다(`/screen`, `/` 모두 자동으로 열리지 않음).

## 4. 단계별 구성

| 단계 | 초점 | 주 행동 |
| --- | --- | --- |
| attract | 실제 인화물 한 장과 역명판, "Touch to start" | 화면 어디나 |
| language | English / 한국어 큰 면 둘 | 면 선택 |
| intro | 네 정거장 노선 | Next |
| cuts | 4컷, 8컷 실물 프레임 두 장 | Next |
| frame | 가운데 프레임(가로 밀기) | Use this frame |
| pay | 7,000원과 인화 2장, 수단 넷(카드, 삼성페이, 현금, 쿠폰) | 수단 선택 뒤 각 수단의 한 가지 행동 |
| guide | 승강장별 포즈 네 개 | Next |
| retouch | 실시간 미리보기, 필터 넷과 피부 보정 | Next |
| ready | 미리보기와 얼굴 타원(기능용 점선 허용), 렌즈 팁 | Start shooting |
| shoot | 미리보기와 카운트다운, 컷 정거장 | 없음(자동) |
| select | 인화 미리보기, 찍은 컷 | Print |
| print | 인화되는 스트립, 스탬프와 메모 | Get my prints |
| finish | 출구 표지와 결과 페이지 QR | Start over |

## 5. 시뮬레이터

1. 기기 실측 비율(geometry.js)은 그대로 두고, 표시 구도만 문 위 트레이까지로 줄여(RATIO 1.3에서 1.16) 같은 화면 높이에서 모니터가 약 15% 커진다.
2. 데스크톱은 기기 위 아일랜드 자리를 줄여 높이를 기기에 더 준다.
3. 투어는 "Take the tour" 버튼으로만 시작한다.
