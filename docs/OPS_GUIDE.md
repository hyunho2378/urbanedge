# 운영 화면 사용 안내 (코딩을 몰라도 되는 설명서)

운영 화면은 키오스크 3대의 매출, 가격, 쿠폰, 카메라를 한곳에서 보고 바꾸는 화면이다. 주소는 `https://urbanedge-kiosk.vercel.app` 이다.
화면 오른쪽 위쪽 1/3은 **카메라**, 아래쪽 2/3은 **대시보드와 관리 탭**이다. 탭은 `대시보드 / 상품·가격 / 프레임 / 쿠폰 / 거래·환불 / 설정` 여섯 개다.

> 이 화면은 서버 없이 이 탭 안에서만 돈다. 페이지를 새로 열면 처음 값으로 돌아간다. 바꾼 설정은 **설정 탭에서 파일로 저장**해 두고, 다음에 같은 탭에서 불러온다.

## 1. 가격을 바꾼다
1. `상품·가격` 탭을 연다.
2. 바꿀 상품 줄의 **가격(원)** 칸을 누르고 숫자를 고친다.
3. 키오스크 결제 화면에 다음 결제부터 바로 반영된다. 따로 저장 버튼은 없다.

## 2. 상품을 더하거나 뺀다
- 더하기: 같은 탭 아래 `상품 추가`에 이름, 컷 수, 인화 장수, 가격을 쓰고 `추가`를 누른다.
- 잠시 빼기: 상품 줄 오른쪽 **판매 스위치**를 끈다. 켜면 다시 나온다.
- 지우기: 직접 추가한 상품만 줄 끝에 휴지통이 보인다.

## 3. 프레임을 켜고 끄거나 더한다
1. `프레임` 탭을 연다.
2. 프레임마다 스위치로 키오스크에 보일지 정한다.
3. `프레임 추가`에 이름, 배경색, 글자색, 컷 수를 고르고 `프레임 추가`를 누른다. 프레임은 데이터 한 줄이라서 프로그램을 다시 만들 필요가 없다.

## 4. 제휴처 일일 코드를 만든다 (예: 올리브 카페)
1. `쿠폰` 탭의 `제휴처 일일 코드`에 제휴처 이름과 할인 금액을 쓴다.
2. 오늘 날짜로 만든 코드가 크게 나온다. `코드 복사`로 영수증 하단 문구에 붙인다.
3. 코드는 날짜가 바뀌면 자동으로 다른 코드가 되므로 매일 손으로 바꿀 일이 없다. `오늘 코드 등록`을 눌러야 키오스크가 그 코드를 받는다.
4. 한 번만 쓰는 코드가 필요하면 `1회용 코드 묶음`에서 개수와 할인 금액을 넣고 만든다.

## 5. 환불한다
1. `거래·환불` 탭에서 해당 결제 줄을 찾는다. 부스나 결제수단으로 걸러서 볼 수 있다.
2. 줄 오른쪽 `환불`을 누르고 확인 창에서 한 번 더 누른다.
3. 환불된 줄은 취소선이 생기고 매출에서 빠진다. 일 마감 영수증에서도 제외된다.

## 6. 하루를 마감한다
`거래·환불` 탭 위쪽 `일 마감` 카드에서 오늘 결제수단별 합계를 본다. `영수증` 버튼으로 일 마감 영수증 화면을 연다.

## 7. 대시보드를 전체 화면으로 본다
- 같은 화면 안에서: `대시보드` 탭 오른쪽 위 `전체화면`을 누른다. 끝낼 때는 `전체화면 끝내기`나 키보드 `Esc`.
- 모니터나 TV에서: 새 탭에 `…/dashboard` 주소를 연다. 운영 화면을 연 탭이 켜져 있는 동안 같은 숫자가 실시간으로 따라온다. 연결이 없으면 `연결 대기 중`이라고 나온다.

## 8. 설정을 저장하고 불러온다
- `설정` 탭 → `설정 파일 저장`: 가격, 상품, 프레임, 쿠폰, 카메라 설정이 파일 하나(`urbanedge-settings-날짜.json`)로 내려받아진다. 안전한 폴더에 보관한다.
- `설정 파일 불러오기`: 저장해 둔 파일을 고르면 같은 설정으로 돌아온다. 이 앱에서 저장한 파일이 아니면 이유를 알려 주고 아무것도 바꾸지 않는다.

## 9. 카메라가 어둡거나 이상할 때
화면 위쪽 카메라 영역에서 부스 탭(레트로, 노래방, 지하철)을 고른 뒤 슬라이더를 움직인다.
- 레트로 방이 어둡게 나오면 `밝기`를 올리고 `색온도`를 따뜻한 쪽으로 조금 옮긴다.
- 거울처럼 좌우가 뒤집혀 보이면 `좌우 반전`을 켜고 끈다.
- 잘 안 되면 `기본값`으로 돌아간다.
바꾼 값은 촬영된 사진에도 같은 값으로 들어간다.

## 10. 화면에서 보이는 숫자의 뜻
| 이름 | 뜻 |
|---|---|
| 매출 | 환불을 뺀 결제 금액의 합 |
| 결제 건수 | 환불을 뺀 결제 수 |
| 객단가 | 매출 ÷ 결제 건수 |
| 어제 같은 시각 대비 | 어제 0시부터 지금과 같은 시각까지의 값과 비교 |
| 지난 기록 불러오기 | 올해 1월 1일부터 어제까지의 기록을 채워 월별, 연간 보기를 확인한다 |

## 문제가 생기면
- 숫자가 안 바뀐다: 페이지를 새로 열면 모두 처음으로 돌아간다. 설정 파일을 불러온다.
- `/dashboard` 탭이 `연결 대기 중`이다: 운영 화면 탭이 같은 브라우저에서 열려 있는지 확인한다.
- 설정 파일이 안 불러와진다: 화면에 나온 이유를 읽고, 다른 파일이면 `설정 파일 저장`으로 만든 파일을 고른다.
